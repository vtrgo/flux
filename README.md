# Flux

Flux is a clean, focused, and straightforward issue tracker designed to help you manage bugs, tasks, and project features effectively. 

## Our Journey

The development journey of Flux is something worth writing home about. It originally started its life with a simple goal: to be an efficient issue tracker. However, as development progressed, ambition took over and the project momentarily grew into something much larger and more complex, encompassing features far beyond its original scope. 

Eventually, we realized that simplicity, focus, and doing one thing exceptionally well are paramount. Flux was thoughtfully refactored and stripped back to its core identity. Today, it has settled down into exactly what it was always meant to be: a dedicated, straight-to-the-point issue tracker that gets out of your way and lets you work.

## Features

- **Focused Issue Tracking:** No bloat, just the essential tools you need to track and resolve issues.
- **Fast and Lightweight:** Built with Go for high performance and a snappy user experience.
- **Clean Interface:** An intuitive frontend designed for productivity.
